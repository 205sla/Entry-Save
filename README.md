# Entry Save Manager 💾

> 엔트리(Entry) 작품에 **세이브/로드** 기능을 블록 몇 개로 붙일 수 있게 해 주는 Chrome 확장 프로그램

![version](https://img.shields.io/badge/version-1.3.7-blue)
![manifest](https://img.shields.io/badge/manifest-v3-green)
![platform](https://img.shields.io/badge/platform-Chrome-brightgreen)

[playentry.org](https://playentry.org)에서 만든 작품의 **`@`로 시작하는 변수·리스트**만 추적해 브라우저 localStorage에 저장합니다. 다른 작품의 세이브를 불러오는 교차 작품 로드도 지원하며, 모든 데이터는 사용자의 브라우저에만 머물러 외부 서버로 전송되지 않습니다.

---

## ⚡ 빠른 시작

작품에 세이브 기능을 붙이는 최소 절차:

1. 저장하고 싶은 변수·리스트 이름 앞에 `@`를 붙이기 (예: `@레벨`, `@인벤토리`)
2. 매개변수 없는 함수 `@저장`을 만들어 저장하고 싶은 시점에 호출
3. 끝. 작품이 실행되면 이전 저장본이 자동 복원되고, `@저장` 호출 시 현재 값이 저장됨

선택 기능: `@확장프로그램` 변수(자동으로 `1`로 세팅), `@가져오기` 함수(다른 작품의 세이브 로드)

---

## 🚀 설치 방법

1. 우측 **[Code] → [Download ZIP]** 으로 저장소 내려받기 후 압축 해제
2. 크롬 주소창에 `chrome://extensions/` 입력
3. 우측 상단의 **개발자 모드** 토글 ON
4. **[압축해제된 확장 프로그램을 로드합니다]** 클릭 → 푼 폴더 선택
5. (권장) 툴바에 아이콘 고정 📌

---

## ✨ 주요 기능

### 🔄 자동 불러오기
작품이 실행(`run`) 상태로 전환되는 즉시 이전 저장본을 자동 복원합니다. `/project/` 자동 실행, `/ws/` Play 버튼, `/noframe/` 임베드 모두 대응.

### 💾 수동 저장 — `@저장` 함수
작품 안에서 매개변수 없는 함수 `@저장`을 호출하면 그 순간 모든 `@` 변수·리스트가 localStorage에 저장됩니다. 저장 시점은 창작자가 자유롭게 결정 (메뉴 저장 버튼, 스테이지 클리어 등).

### 🔗 교차 작품 불러오기 — `@가져오기` 함수
다른 작품의 세이브를 현재 작품으로 가져옵니다. 시리즈 작품 1편의 엔딩 데이터를 2편에서 이어받는 시나리오에 유용.

```
@가져오기 [69b3ef8e0075070c7c1d0aca]   ← 다른 작품의 project ID
```

문자/숫자값 파라미터 한 개로 대상 작품 ID를 받아, **현재 작품에도 같은 이름으로 존재하는** `@` 변수·리스트만 복원합니다. 파라미터 자리엔 글상자·변수값·계산식 모두 가능 (모두 런타임에 평가).

### 🎯 확장 설치 감지 — `@확장프로그램` 변수
작품에 `@확장프로그램`이라는 **변수**를 만들어두면 확장이 활성화된 상태로 실행 시 자동으로 `1`이 됩니다. "세이브 기능은 확장을 켜야 사용 가능합니다" 같은 안내를 조건부로 표시할 때 활용하세요.

### 🧭 만들기/작품보기 데이터 분리
`/ws/` 워크스페이스(만들기)와 `/project/` 작품보기는 **서로 다른 저장 공간**을 사용해 제작 중 테스트 데이터와 플레이어 진행도가 섞이지 않습니다.

### 🗑 데이터 관리 팝업
확장 아이콘 클릭으로 열리는 팝업에서 **현재 작품 초기화** / **모든 작품 초기화**를 지원. "현재 작품 초기화"는 현재 페이지의 namespace만 삭제 (`/ws/`에서 누르면 만들기 데이터만, `/project/`에서 누르면 작품보기 데이터만).

## 🎮 작품 제작 가이드

### 1. 변수/리스트 명명 규약 (필수)
저장하고 싶은 변수·리스트 이름 앞에 `@`를 붙입니다.

```
✓ @레벨, @골드, @인벤토리_리스트, @최고기록
✗ 레벨,  골드                    (추적되지 않음)
```

### 2. `@저장` 함수 만들기 (필수)
엔트리의 **[함수 만들기]** 로 매개변수 없는 함수 `@저장`을 정의합니다. 플레이어가 저장해야 할 시점에 이 함수를 호출하면 그 순간 localStorage에 반영됩니다.

### 3. `@가져오기` 함수 만들기 (선택)
**문자/숫자값 입력** 파라미터 하나를 받는 함수 `@가져오기`를 정의합니다. 파라미터로 대상 작품의 project ID를 넘겨 호출.

작품 ID는 URL에서 확인:
```
https://playentry.org/project/69e1cf125ccad8d458628c6f
                              ↑ 이 부분
```

### 4. `@확장프로그램` 변수 만들기 (선택)
같은 이름의 **변수**(리스트 아님)를 추가만 해두면 확장 실행 시 자동으로 `1`이 됩니다. 조건 블록으로 분기시켜 사용자에게 확장 설치 여부를 안내하세요.

## 💾 저장 키 규칙

localStorage에 저장되는 키 형식:

| 페이지 | 키 형식 | 비고 |
|---|---|---|
| `/project/<id>` | `entry_save_<id>` | 기본 (대다수 사용자) |
| `/noframe/<id>` | `entry_save_<id>` | `/project/`와 동일 namespace |
| `/ws/<id>` | `entry_save_ws_<id>` | 워크스페이스 전용 |
| `@가져오기(<otherId>)` | `entry_save_<otherId>` | 호출 페이지 무관, 항상 작품보기 데이터 |

## 🐛 문제 해결

**Q. 저장은 되는데 불러와지지 않습니다**
- 변수·리스트 이름이 정확히 `@`로 시작하는지 확인
- 작품을 새로 저장하면 project ID가 바뀌어 기존 저장본과 연결이 끊길 수 있음
- **만들기(`/ws/`)와 작품보기(`/project/`)는 별도 저장 공간**입니다 — 만들기에서 저장한 데이터는 작품보기에서 자동 로드되지 않습니다 (반대도 마찬가지)
- 개발자도구(F12) 콘솔에서 `[Entry Save Manager] 저장된 데이터 로드: ...` 로그 확인 (디버그 모드)

**Q. `@확장프로그램`이 `1`로 안 바뀝니다**
- 변수 이름에 공백/추가 문자 없는지 확인 (`@확장프로그램` 정확히)
- **리스트**가 아니라 **변수**로 만들었는지 확인
- 작품이 완전히 실행(`run`) 상태로 진입한 뒤 확인 (`/project/`에서 자동 실행이 안 일어나면 화면을 한 번 클릭해 user gesture 발생)

**Q. `@가져오기`가 동작하지 않습니다**
- 파라미터가 hex 형식의 project ID인지 확인 (예: `69e1cf125ccad8d458628c6f`)
- 대상 작품에 이전에 `@저장`으로 저장한 데이터가 실제로 있는지 확인
- `@가져오기` 함수의 파라미터 타입이 **문자/숫자값**인지 확인

## 🔒 안전성 & 개인정보

- **추적 대상은 `@` 접두사 변수/리스트만** — 일반 데이터는 건드리지 않음
- **로드 시 primitive 타입 검증** (number/string/boolean만 허용) — 변조된 객체·함수 주입 차단
- **손상된 JSON은 항목별로 스킵**하고 나머지는 정상 복원
- **대상 프로젝트 ID는 hex 패턴 검증** 후 접근
- **모든 데이터는 기기 내부(localStorage)에만 저장** — 네트워크 전송 일체 없음

---

## 📌 제한 사항

- **localStorage 기반** → 브라우저/프로파일별로 독립, 기기 간 동기화 불가
- 엔트리 내부 API가 크게 변경되면 후킹이 동작하지 않을 수 있음 (확장 업데이트 필요)
- **primitive 타입(number/string/boolean)만 복원** — 객체·배열이 들어간 값은 해당 항목만 스킵

## 🛠 기술적 특징

- **Manifest V3** 완전 준수
- **MAIN world 주입**으로 `window.Entry` 엔진 내부 상태·함수에 직접 접근
- **postMessage 핸드셰이크**로 자식 iframe이 부모 frame의 페이지 타입(ws/project)을 안전하게 받음
- **SPA Mutation Observer** — 엔트리 라우팅 변경 시 `inject.js` 재주입
- **삼중 실행 감지**:
  1. `Entry.engine.toggleRun` 후킹 (사용자 Play 버튼)
  2. 상태 폴링 (`stop → run` 전이)
  3. 초기 진입 시 이미 `run` 상태이면 즉시 로드 (`/project/` 자동 실행)
- **signature 기반 후킹 관리** (`_isSaveMgrHook`) — URL 변경 시 자기 래퍼만 정확히 복구해 중복 래핑·좀비 후킹 방지
- **런타임 파라미터 추출** — `@가져오기`의 인자는 호출 블록의 `this.values`에 채워진 평가된 값을 사용 (리터럴 글상자·변수 블록·계산식 모두 동작)

## 📦 버전

현재: **v1.3.7**

- **v1.3.7** — 엔트리 업데이트로 작품보기 전체화면(⛶) 시 `Entry.engine`이 새 객체로 교체되며 자동 불러오기·`@확장프로그램` 설정이 끊기던 문제 수정. 폴링 루프에 engine 교체 감지를 추가해 새 engine에 `toggleRun`을 즉시 재후킹하고, 이미 실행 중이면 곧바로 복원. (스토어 빌드 정리: 매치 도메인을 `playentry.org` 전용으로 축소(로컬 제거), `@저장` 미정의 작품에서 뜨던 콘솔 에러 침묵)
- **v1.3.x** — 만들기(`/ws/`)와 작품보기(`/project/`) namespace 분리, `/noframe/<id>` 임베드 페이지 지원, 자식 iframe pageType postMessage 핸드셰이크, `@가져오기`는 항상 작품보기 namespace 사용
- **v1.2.1** — 팝업 푸터에 "도구.엔트리.org" 패밀리 사이트 링크 추가
- **v1.2.0** — `@가져오기` 교차 작품 불러오기, primitive 타입 검증, 후킹 signature 가드, `/project/` 초기 자동 실행 대응
- **v1.0.x** — 초기 공개 (`@저장`, `@확장프로그램`, 자동 불러오기)
