# Entry Save Manager (엔트리 세이브 매니저) 💾

> 엔트리(Entry) 작품의 변수·리스트 데이터를 브라우저에 저장·복원하고, 다른 작품의 세이브까지 불러올 수 있게 해 주는 Chrome 확장 프로그램입니다.

![version](https://img.shields.io/badge/version-1.2.0-blue)
![manifest](https://img.shields.io/badge/manifest-v3-green)
![platform](https://img.shields.io/badge/platform-Chrome-brightgreen)

---

## 📖 소개

[playentry.org](https://playentry.org)에서 제작한 작품에 몇 개의 블록만으로 **세이브/로드** 기능을 붙일 수 있게 해 줍니다. 작품 내부에서 이름이 `@`로 시작하는 변수·리스트만 추적하며, 모든 데이터는 사용자의 브라우저 localStorage에만 보관됩니다. 외부 서버로 전송되는 정보는 하나도 없습니다.

---

## ✨ 주요 기능

### 🔄 자동 불러오기
작품이 실행(`run`) 상태로 전환되는 즉시, 이전에 저장된 데이터를 감지하여 자동으로 복원합니다. `/project/` 자동 실행과 `/ws/` Play 버튼 모두 대응.

### 💾 수동 저장 — `@저장` 함수
작품 안에서 `@저장` 함수를 호출하는 순간, `@` 접두사가 붙은 모든 변수·리스트가 localStorage에 저장됩니다. 저장 시점은 창작자가 자유롭게 결정(메뉴 저장 버튼, 스테이지 클리어 등).

### 🔗 교차 작품 불러오기 — `@가져오기` 함수 *(v1.2.0 NEW)*
다른 작품에 저장된 세이브 데이터를 현재 작품으로 가져올 수 있습니다. **문자/숫자값** 파라미터 한 개로 대상 작품의 ID를 받아, 해당 작품의 `@` 변수·리스트 중 **현재 작품에도 같은 이름으로 존재하는 것**만 복원합니다. 시리즈 작품 1편의 엔딩 데이터를 2편에서 이어받는 시나리오 등에 유용합니다.

```
@가져오기 [69b3ef8e0075070c7c1d0aca]   ← 다른 작품의 project ID
```

파라미터 자리엔 글상자·변수값·계산식 모두 꽂을 수 있으며 전부 런타임에 평가됩니다.

### 🎯 확장 설치 감지 — `@확장프로그램` 변수
확장이 활성화된 상태에서 작품을 실행하면 `@확장프로그램` 변수가 자동으로 `1`로 세팅됩니다. 작품 안에서 "세이브 기능은 확장을 켜야 사용 가능합니다" 같은 안내를 조건부로 표시할 수 있습니다.

### 🗑 데이터 관리 팝업
확장 아이콘 클릭 시 나타나는 팝업에서 **현재 작품 데이터 초기화** / **모든 작품 데이터 초기화**를 지원합니다.

## 🔒 안전성 & 개인정보

- 추적 대상은 **`@` 접두사 변수/리스트**에 한정 — 일반 데이터는 건드리지 않습니다.
- 로드 시 **primitive 타입 검증**(number·string·boolean만 허용) — 변조된 객체·함수 주입 차단.
- 손상된 JSON은 항목별로 스킵하고 나머지는 정상 복원.
- 대상 프로젝트 ID는 hex 패턴 검증 후 접근.
- 모든 데이터는 **기기 내부(localStorage)** 에만 저장되며 네트워크로 전송되지 않습니다.

| 파일 | 실행 환경 | 역할 |
|---|---|---|
| `manifest.json` | — | Manifest V3 정의, playentry.org 스코프 |

## 🚀 설치 방법

1. 우측 **[Code] → [Download ZIP]** 으로 저장소 내려받기 후 압축 해제
2. 크롬 주소창에 `chrome://extensions/` 입력
3. 우측 상단의 **개발자 모드** 토글 활성화
4. **[압축해제된 확장 프로그램을 로드합니다]** 클릭 → 앞서 푼 폴더 선택
5. 툴바에 아이콘 고정 📌 (권장)

## 🎮 엔트리 작품 제작 가이드

### 1. 변수/리스트 명명 규약
저장하고 싶은 변수·리스트 이름 앞에 반드시 `@`를 붙입니다.

```
✓ @레벨, @골드, @인벤토리_리스트, @최고기록
✗ 레벨,  골드                    (추적되지 않음)
```

### 2. `@저장` 함수 만들기 (필수 — 저장 기능)
엔트리의 **[함수 만들기]** 로 매개변수 없는 함수 `@저장`을 정의합니다. 플레이어가 저장해야 할 시점에 이 함수를 호출하도록 블록을 조립하면 그 순간 localStorage에 반영됩니다.

### 3. `@가져오기` 함수 만들기 (선택 — 교차 작품 로드)
**문자/숫자값 입력** 파라미터 하나를 받는 함수 `@가져오기`를 정의합니다. 파라미터로 대상 작품의 project ID를 넘겨 호출하면, 해당 작품에 저장된 `@` 변수/리스트 중 **현재 작품에도 같은 이름으로 존재하는 항목**만 복원됩니다.

작품 ID는 URL에서 확인:
```
https://playentry.org/project/69e1cf125ccad8d458628c6f
                              ↑ 이 부분
```

### 4. 확장 감지 (선택)
`@확장프로그램`이라는 **변수**(리스트 아님)를 만들어 두면, 확장 활성 상태로 작품이 실행될 때 자동으로 `1`이 됩니다. 조건 블록에서 분기시켜 안내 메시지를 띄우는 용도로 활용하세요.

## 🛠 기술적 특징

- **Manifest V3** 완전 준수 (최신 크롬 정책 대응)
- **MAIN world 주입**으로 `window.Entry` 엔진 내부 상태·함수에 직접 접근
- **SPA Mutation Observer** — 엔트리 라우팅 변경 시 inject.js 재주입
- **삼중 실행 감지**
  1. `Entry.engine.toggleRun` 후킹 (사용자 Play 버튼)
  2. 상태 폴링 (`stop → run` 전이)
  3. 초기-`run` 즉시 로드 (`/project/` 자동 실행)
- **signature 기반 후킹 관리** (`_isSaveMgrHook`): URL 변경 시 원본 함수를 signature 체크 후 정확히 복구하여 중복 래핑·좀비 후킹 방지
- **런타임 파라미터 추출**: `@가져오기`의 인자는 Entry 런타임이 호출 블록의 `this.values`에 채운 **평가된 값**을 사용 — 리터럴 글상자·변수 블록·계산식 모두 동작

## 📌 제한 사항

- `localStorage` 기반이므로 **브라우저/프로파일별로 독립** — 기기 간 동기화는 지원하지 않습니다.
- 엔트리 내부 API가 크게 변경되면 후킹이 동작하지 않을 수 있으며 이 경우 확장 업데이트가 필요합니다.
- primitive 타입(number·string·boolean)만 복원됩니다. 과거 버전이나 수동 편집으로 객체·배열이 들어간 값은 해당 항목만 스킵됩니다.

## 🐛 문제 해결

**Q. 저장은 되는데 불러와지지 않습니다**
- 변수·리스트 이름이 정확히 `@`로 시작하는지 확인하세요.
- 작품을 새로 저장하면 project ID가 바뀌어 기존 저장본과 연결이 끊길 수 있습니다.
- 개발자도구(F12) 콘솔에서 `[Entry Save Manager] 저장된 데이터 로드: ...` 로그 확인.

**Q. `@확장프로그램`이 `1`로 안 바뀝니다**
- 변수 이름에 공백이나 추가 문자가 없는지 확인(`@확장프로그램` 정확히).
- **리스트**가 아니라 **변수**로 만들었는지 확인.
- 작품이 완전히 실행(`run`) 상태로 진입한 뒤 확인.

**Q. `@가져오기`가 동작하지 않습니다**
- 파라미터가 hex 형식의 project ID인지 확인 (예: `69e1cf125ccad8d458628c6f`).
- 대상 작품에 이전에 `@저장`으로 저장한 데이터가 실제로 있는지 확인.
- 콘솔에 `"@가져오기" 호출 — 소스 ID: ...` 로그가 나오는지 확인.
