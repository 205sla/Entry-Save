# Entry Save Manager (엔트리 세이브 매니저) 💾

엔트리(Entry) 작품의 특정 변수와 리스트 데이터를 로컬 환경에 저장하고 자동으로 불러올 수 있도록 지원하는 크롬(Chrome) 확장 프로그램입니다.

## ✨ 주요 기능

* **자동 불러오기**: 엔트리 작품이 실행(`run`) 상태로 전환될 때, 이전에 저장된 데이터를 감지하여 자동으로 복원합니다.
* **수동 데이터 저장**: 작품 내에서 지정된 함수(기본값: `@저장`)를 호출하는 즉시 브라우저 로컬 스토리지에 데이터가 안전하게 저장됩니다.
* **선택적 추적 저장**: 이름이 `@`로 시작하는 **변수** 및 **리스트** 데이터만 추적합니다. (예: `@골드`, `@인벤토리_리스트` 등)
* **확장 프로그램 상태 연동**: 확장 프로그램이 활성화된 경우 자동으로 `@확장프로그램` 변수 값을 `1`로 변경하여, 작품 안에서 확장 프로그램 설치 여부 검사를 구현할 수 있습니다.
* **데이터 리셋 팝업 UI**: 제공되는 팝업 UI를 통해, 현재 접속 중인 작품 데이터 초기화 또는 저장된 모든 작품의 데이터 초기화를 손쉽게 관리할 수 있습니다.

## 📁 주요 파일 구조

* `manifest.json`: 확장 프로그램의 설정 파일 (Manifest V3 적용).
* `inject.js`: 웹페이지 내에 삽입되어 실행되는 핵심 스크립트. `MAIN` world 환경에서 실행되어 `window.Entry` 객체에 직접 접근하고 작동 로직을 제어합니다.
* `content.js`: 확장 프로그램과 엔트리 웹페이지 간의 브릿지 파일. SPA 환경에 대응하여, URL이 변경될 때 `inject.js` 재삽입 등 안전장치 역할을 수행합니다.
* `popup.html`, `popup.js`: 확장 프로그램 아이콘을 클릭했을 때 나타나는 UI로 저장소 현황을 확인하고, 삭제할 수 있는 기능입니다.

## 🚀 설치 방법

1. 우측의 **[Code]** 버튼을 눌러 **[Download ZIP]**을 클릭한 뒤, 적당한 폴더에 압축을 풉니다.
2. 구글 크롬 브라우저를 켜고 주소창에 `chrome://extensions/`를 입력하여 설정 페이지로 들어갑니다.
3. 우측 상단의 **개발자 모드** 토글 버튼을 활성화합니다.
4. 좌측 상단에 나타나는 **[압축해제된 확장 프로그램을 로드합니다.]** 버튼을 클릭합니다.
5. 앞서 압축을 풀어둔 해당 폴더를 선택하여 업로드합니다.
6. 활성화된 **Entry Save Manager** 아이콘을 확인할 수 있습니다! (고정하시면 사용이 더 편리합니다.)

## 🎮 엔트리 작품 제작 가이드

본 확장 프로그램을 제대로 테스트하거나 활용하기 위해서는 작품 내에서 다음 스펙을 따라주셔야 합니다.

1. **저장할 변수 및 리스트 생성**: 저장하길 원하는 변수와 리스트의 이름 앞에는 필수적으로 `@`를 붙여야 합니다. 
   - 예시: `@레벨`, `@소지품`
2. **저장 트리거 생성**: 엔트리 함수 만들기 기능을 통해 함수 이름을 `@저장`으로 생성합니다.
   - 플레이어가 저장을 원하는 시점(예: 메뉴의 저장 버튼 클릭, 스테이지 클리어)에 이 함수를 실행되도록 블록을 조립하세요. 확장 프로그램이 이 함수의 동작을 후킹(Hooking)하여 저장을 수행합니다.
3. **확장 프로그램 감지 (선택)**: `@확장프로그램`이라는 변수를 만들어 주세요. 플레이어가 확장 프로그램을 설치하고 작품을 실행하면, 로딩 직후 자동으로 이 값을 `1`로 바꿔줍니다. 이를 통해 플레이어에게 저장 기능 사용 가능 여부를 안내할 수 있습니다.

## 🛠 기술적 특징
* **Manifest V3**: 최신 구글 정책에 완벽하게 부합합니다.
* **World MAIN Context**: `world: "MAIN"` 속성을 통해 우회 없이 직접 메인 창의 상태를 수정하고 엔트리의 내장 엔진 상태를 감지합니다.
* **SPA Mutation Observer**: 엔트리의 폴더 구조, 경로 변경 등 SPA 라우팅 기능에 완벽하게 대응합니다.
